# Project One

Professional Discord.js bot. No website and no Dashboard.

## Systems
Slash + Prefix commands, Arabic prefix aliases, moderation, audit logs, anti-spam, anti-raid, AutoMod, welcome, autorole, tickets, suggestions and configurable protection.

## Setup
Node.js 20+, copy .env.example to .env, set DISCORD_TOKEN, optionally set CLIENT_ID, edit config.js, then run npm install && npm start.
